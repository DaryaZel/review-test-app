# review-test-app

A small task list built with Vite, React and TypeScript.

Features: add tasks, mark them done, delete them, filter by all / active / completed,
search with match highlighting, and add tasks from a list of suggestions.
Tasks are saved to localStorage.

## Scripts

```bash
npm install
npm run dev     # start the dev server
npm run build   # type-check and build for production
npm run lint    # run ESLint
```
